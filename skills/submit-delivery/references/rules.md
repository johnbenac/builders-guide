# Rules for this skill

Generated from rules.json. Level, statement, how to check, fix hint.

| Rule | Level | Statement | Check | Fix hint |
|---|---|---|---|---|
| X-70 | required | Put a submitted delivery in `deliveries/<slug>/` with a `delivery.json` whose `delivery.id` equals the slug and whose `submission` object states the title, the submitter handle, the licence, the profile used, the tool versions and the attestation. | tools/check_submission.py | Rename the folder to the slug used as delivery.id, add the missing fields to the submission object of delivery.json (schemas/submission.schema.json) and rerun. |
| X-71 | required | Offer the delivery under a licence the profile lists (`submission.allowedLicences`; by default CC BY 4.0, or CC0 when the delivery says so). | tools/check_submission.py | Set submission.licence to one of the licences the profile lists (CC-BY-4.0 or CC0-1.0 by default) and make the provenance entries agree. |
| X-72 | required | Include only files of the types the profile lists (`submission.allowedExtensions`; by default ifc, glb, png, jpg, json, md, csv and txt), with no program, script or archive and no executable file mode. | tools/check_submission.py | Remove the file, or convert the content to a listed type (ifc, glb, png, jpg, json, md, csv, txt); clear the executable bit with chmod -x. |
| X-73 | required | Keep a delivery within the profile's limits: at most `submission.maxFiles` files (200), `submission.maxFileBytes` per file (25 MiB) and `submission.maxDeliveryBytes` in total (100 MiB). | tools/check_submission.py | Remove files that are not needed, reduce texture sizes or geometry, or split the delivery into two deliveries. |
| X-74 | required | Use only relative, portable paths: no leading slash, no `..`, no backslash or drive letter, names of letters, digits, dot, hyphen and underscore that do not start with a dot, no reserved device names, no two names that differ only by case, and no path longer than `submission.maxPathLength`, in the folder and in every path the manifest and the checksum list name. | tools/check_submission.py | Rename the file to letters, digits, dot, hyphen and underscore, without a leading dot, and make every path in delivery.json and SHA256SUMS.txt relative with forward slashes. |
| X-75 | required | Include no symbolic link and no special file, only plain files and folders. | tools/check_submission.py | Replace the link by a copy of the file it points to. |
| X-76 | required | Have the submitter attest in `submission.attestation` that the work is their own or they may offer it, that they may license it under the stated licence, and that it holds no restricted third-party content. | tools/check_submission.py | Set the three attestation fields to true only if they are true, otherwise do not submit the delivery. |
| X-77 | required | Make every file what its name says: PNG and JPEG images that are real images within `submission.maxImagePixels`, GLB files that are binary glTF 2 of the stated length, IFC files that are IFC text files, JSON that parses, text in UTF-8 without NUL bytes or active markup (script, iframe, object, embed). | tools/check_submission.py | Re-export the file in the type its name says, within the pixel limit, or rename it to its real type if that is allowed. |
| X-78 | recommended | Add at least one preview picture under `previews/` (or `items/<id>/preview.png`) so a reviewer sees the work before opening a model. | tools/check_submission.py | Add a rendered or plotted picture to previews/ (tools/preview.py draws plans and an isometric view). |
